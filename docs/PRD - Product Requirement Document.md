# PRD - Product Requirement Document
<strong>("How the Product will behaves?")</strong>

**1.Overview**

*1.1 Purpose*

This document defines requirements for MyAgenda app, including messages, users and groups. 

*1.2 Target Users*

* Company employees.

**2.Key Features**

*2.1 Users*

- Users should be able to find, save and delete contacts.
- Users should be able to find, save, delete or be part of a group.
- Users should be able to save they contact info like address, phone number, company and also they can have a space to put a phrase that will be shown in their profiles.

*2.2 Groups*

- A group can be search by name or ID.
- A group must have at least one admin, who also can be the group's owner.
- The group's admins are the only ones that can add contact in the group.
- The group's owner is the only that can delete the group.
- Anyone can create a group.

*2.3 Messages*

- A user can send a message to another user.
- A message can be send into a group to many users. 

**3.Success Metrics**

- Improve company communication
- Guarantee information security 99.9% under the app
